# Acervo de Estudos

Repositório da minha documentação pessoal construída com [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

## Desenvolvimento local

```bash
pip install -r requirements.txt  # caso necessário
mkdocs serve
```

A documentação ficará disponível em `http://localhost:8000`.

## Estrutura

- `mkdocs.yml` — configurações do site e navegação.
- `docs/` — arquivos Markdown organizados por área de estudo.
  - `index.md` — página inicial com apresentação e projetos em destaque.
  - `backend/`, `frontend/`, `devops/` — seções temáticas com planos de estudo e referências.

Sinta-se à vontade para explorar e acompanhar a evolução do meu aprendizado! 😊
