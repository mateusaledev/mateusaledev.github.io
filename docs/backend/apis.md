# APIs e Serviços

Nesta página vou reunir tudo que estudo sobre criação de APIs: desde conceitos fundamentais até padrões avançados de design e segurança.

## Plano de estudo

1. **Modelagem de recursos** — entender como estruturar endpoints de forma consistente.
2. **Autenticação e autorização** — explorar JWT, OAuth2 e melhores práticas.
3. **Observabilidade** — registrar métricas e logs para manter serviços saudáveis.
4. **Documentação** — usar OpenAPI/Swagger para padronizar contratos.
